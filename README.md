# 01 · SEO 内容站 / 工具站自动运营

## 1. 项目概述
用 AI 批量生成"小而实用"的内容页(在线计算器、单位转换、常见问答、攻略清单),搭成网站,靠 Google AdSense / 国内广告联盟的点击和展示分成赚钱。全流程可无人值守:选题 → 生成 → 发布 → 收录 → 分成。

## 2. 收益模型与预期
- 收入:AdSense 点击/千次展示 + 国内联盟(百度联盟、360 联盟)+ 少量软文/外链。
- 单站预期:100 篇优质页面后,日 UV 500~2000,月广告收入约 ¥300~1500。
- 放大方式:跑通一个站后复制第二个、第三个站(不同垂直领域),形成站群。
- 时间线:第 1 个月建站 + 发 100 篇;第 2~3 个月等收录;第 4 个月起按数据迭代。

## 3. 自动化流程图
```
关键词挖掘 → AI 生成页面 → 自动排版 → 自动发布 → 提交 sitemap/站长工具
    ↑                                                            ↓
    └──────────── 数据回传,自动淘汰零流量主题 ←──────────────────┘
```

## 4. 技术方案
- 建站方案 A(最省):静态站 Hugo/Astro + GitHub Actions + Cloudflare Pages,零服务器费用。
- 建站方案 B(最省心):WordPress + 宝塔面板,插件生态全,SEO 插件成熟。
- 生成:OpenAI/本地大模型 API + 关键词工具(Google Keyword Planner、百度指数、5118 免费版)。
- 发布:WordPress REST API + Python 定时任务;静态站用 CI 自动构建。
- SEO:生成结构化数据(Schema)、自动 sitemap、文章内链。
- 域名:约 ¥60/年。

## 5. 成本预算
| 项目 | 月成本 |
| --- | --- |
| 域名 | ¥60/年 |
| 服务器 | ¥50~100(静态站可 0) |
| AI API | ¥50~200 |
| 工具订阅 | 0~¥50 |
| 首月合计 | 约 ¥200,之后 ¥100~300/月 |

## 6. 平台与渠道
- 广告:Google AdSense(建议做中英文双语站提权重)、百度联盟、360 联盟。
- 流量:自然搜索为主,配合目录站提交、少量外链。

## 7. 起步行动清单
- 第 1 周:注册域名、搭站,先手写/精修 10~20 篇优质内容,提交 AdSense 审核。
- 第 2 周:跑通"关键词 → 生成 → 发布"脚本,每天自动发 5~10 篇。
- 第 3~4 周:提交百度/Google 站长工具,观察收录率,淘汰 30 天零流量主题。

## 8. 关键指标
- 收录率 > 80%
- 单页 30 天内至少获得 1 次搜索点击
- 第 3 个月日 UV ≥ 500;AdSense 过审

## 9. 风险与合规
- AI 低质内容惩罚:必须人工抽检,添加原创数据、截图、表格提升价值。
- 版权:全部原创生成,不搬运。
- 广告密度:页面内容少、广告多会被联盟拒审。

## 10. 迭代策略
- 每 30 天砍掉零流量主题,资源集中到跑出来的方向。
- 单站月入 ¥500 后开第二站;测试英文站(AdSense 单价更高)。
