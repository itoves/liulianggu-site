## 为什么需要 GPA 换算器？

不同国家、不同学校使用的成绩体系差异很大：国内常用百分制，美国多用 4.0 制，部分欧洲学校用 5 分制或等级制。申请时，招生官需要把你的成绩换算成他们熟悉的体系，手动查表容易出错，**GPA 换算器**可以一键完成转换，减少计算失误。

## 常见 GPA 算法与对照表

GPA 换算没有全球统一标准，常见的有标准 4.0 算法、WES 算法、北大算法等。下面是最常用的百分制→4.0 制对照表（基于标准算法）：

| 百分制分数 | 等级 | 4.0 制 GPA | 常见解释 |
|------------|------|------------|----------|
| 90–100 | A | 4.0 | 优秀 |
| 85–89 | A- | 3.7 | 良好+ |
| 82–84 | B+ | 3.3 | 良好 |
| 78–81 | B | 3.0 | 中等+ |
| 75–77 | B- | 2.7 | 中等 |
| 72–74 | C+ | 2.3 | 及格+ |
| 68–71 | C | 2.0 | 及格 |
| 64–67 | C- | 1.7 | 勉强及格 |
| 60–63 | D | 1.0 | 低空掠过 |
| 60 以下 | F | 0 | 不及格 |

注意：WES 算法对 85 分以上通常给 4.0，而标准算法只给 3.7，所以用不同算法算出的 GPA 可能差 0.3 左右。

## 如何用 GPA 换算器完成转换？

使用在线 GPA 换算器一般只需三步：

1. **输入原始成绩**：选择你的成绩体系（百分制、4.0 制、5 分制等），逐门输入分数和学分。
2. **选择目标算法**：根据申请学校要求，选择标准算法、WES 算法或自定义算法。
3. **查看结果**：工具会自动计算加权平均分，并给出对应的 4.0 制 GPA。

如果没有网络工具，也可以手动换算：先把每门课的百分制分数按对照表换成 GPA 绩点，再乘以该课学分，求和后除以总学分。例如：高数 85 分（3.7×4 学分）、英语 90 分（4.0×2 学分），则 GPA = (3.7×4 + 4.0×2) / (4+2) = 3.8。

## 换算时容易踩的坑

- **学分权重不能忽略**：学分高的课程对 GPA 影响更大，简单平均会失真。
- **选修课和必修课要分开看**：有些学校只算必修课 GPA，申请时需确认。
- **算法不同结果不同**：同一份成绩单，用标准算法可能是 3.5，用 WES 算法可能是 3.7，建议在简历中注明算法。
- **百分制与 4.0 制不是线性关系**：60 分对应 1.0，但 100 分对应 4.0，中间并非等比例。

## 什么时候该用 GPA 换算器？

- 填写网申系统时，需要快速把百分制成绩填成 4.0 制。
- 比较不同学校的录取要求，判断自己是否达标。
- 制作英文成绩单时，附上换算后的 GPA 供招生官参考。
- 申请奖学金或交换项目，对方要求提供 4.0 制 GPA。

如果你还在准备语言考试，可以同时使用我们的雅思分数换算器和托福分数换算器来对比英语成绩。

## 手动换算步骤（无工具时）

1. 列出所有课程的名称、学分、百分制分数。
2. 查对照表，把每门课分数换成 4.0 制绩点。
3. 用「绩点 × 学分」得到每门课的加权值。
4. 把所有加权值相加，除以总学分，得到最终 GPA。
5. 保留两位小数，并注明使用的算法。

例如：三门课分别为 4 学分（85 分，3.7）、3 学分（92 分，4.0）、2 学分（78 分，3.0），则 GPA = (3.7×4 + 4.0×3 + 3.0×2) / (4+3+2) = (14.8 + 12 + 6) / 9 = 3.64。
